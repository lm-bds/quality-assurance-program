# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through a **GitHub Security Advisory** for this repository. Do not include personal contact data or sensitive sample data in a public issue. If private reporting is unavailable, open a minimal public issue asking for an advisory without describing exploit details.

Reports should include the affected revision or release, a concise description of the impact, reproduction steps using synthetic or otherwise non-sensitive inputs, and any suggested mitigation. The scope is this repository and its published source, build, and CI configuration; third-party dependencies should also be reported when the issue is actionable through this project.

## Disclosure

We will acknowledge a private report when practicable, coordinate a fix and disclosure with the reporter, and target public disclosure within 90 days of the initial report. Please allow time for validation and remediation before public disclosure.

`qaprs` processes quality-assurance data and generates reports. It is not a clinical device or clinical decision-making system; use synthetic or de-identified data when reproducing issues.
